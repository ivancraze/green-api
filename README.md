# Чат GREEN-API

Одностраничный чат для личных текстовых сообщений в MAX, WhatsApp и Telegram. Доступны деморежим и подключение собственного инстанса GREEN-API.

## Запуск проекта

Требуется Node.js `^22.22.2`, `^24.15.0` или `>=26.0.0` (рекомендуется 24.15.0+) и npm.

Установите зависимости и запустите сервер разработки:

```sh
npm ci
npm run dev
```

Откройте адрес, который Vite покажет в терминале (обычно `http://localhost:5173/`). Приложение работает в браузере; сервер приложения и переменные окружения не нужны.

Для проверки готовой сборки:

```sh
npm run build
npm run preview
```

При размещении SPA сервер должен возвращать `index.html` для маршрутов `/login`, `/max`, `/whatsapp` и `/telegram`. Для Vercel это правило подготовлено в `vercel.json`; облачное развёртывание ещё не проверено.

## Деморежим

На странице входа оставьте режим «Демо», выберите мессенджер и нажмите «Войти в демо». В списке есть заполненный и пустой чат. Кнопка «Новый чат» открывает форму международного номера; сообщение отправляется кнопкой в поле ввода. После отправки появляется детерминированный тестовый ответ. В окне «Демоотказы» можно включить отказ отправки или получения и затем проверить восстановление. Отказ подключения включается на странице входа.

Демо не использует учётные данные и не отправляет сообщения реальным получателям. Выход или перезагрузка удаляют сессию, черновики и данные текущего запуска.

## Реальное подключение

1. Подготовьте авторизованный инстанс нужного мессенджера и доступного получателя в GREEN-API.
2. В кабинете инстанса откройте настройки уведомлений. Для получения через HTTP API оставьте `webhookUrl` пустым, включите входящие уведомления (`incomingWebhook`) и сохраните настройки. Для отображения подтверждённых статусов исходящих сообщений включите уведомления о статусах, если они доступны для инстанса. Приложение настройки инстанса не меняет.
3. На странице входа выберите «Реальное подключение», мессенджер и введите `apiUrl`, `idInstance`, `apiTokenInstance` из кабинета. Нажмите «Подключиться».
4. Откройте существующий личный чат или создайте новый через «Новый чат» по международному номеру. Отправьте текст и ответьте с аккаунта получателя. Успешная отправка в интерфейсе означает принятие API; доставка показывается только после соответствующего статуса.

В MAX создание чата по номеру поддерживает РФ и РБ. Поиск Telegram может не вернуть пользователя из-за настроек приватности. Показаны только личные текстовые чаты; группы и вложения не поддерживаются. История зависит от данных, доступных сервису: приложение запрашивает последние 100 записей открытого чата. При пустом списке GetChats оно использует журналы сообщений за 14 дней. При выходе и перезагрузке credentials и локальные данные удаляются из памяти браузера; после повторного входа доступная серверная история загружается заново.

Для браузерного подключения API должен разрешать CORS для адреса приложения. Проверка подключения, отправка и получение для MAX требуют отдельной проверки на живом инстансе. Состояние приёмки по каждому мессенджеру записано в [списке сценариев](docs/acceptance.md).

Документация GREEN-API по настройке HTTP API: [MAX](https://green-api.com/v3/docs/api/receiving/technology-http-api/), [WhatsApp](https://green-api.com/docs/api/receiving/technology-http-api/), [Telegram](https://green-api.com/telegram/docs/api/receiving/technology-http-api/).

## Тесты

После установки зависимостей запустите все тесты одной командой:

```sh
npm test
```

Дополнительные проверки: `npm run lint` и `npm run lint:antd`.
