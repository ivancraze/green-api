# Тестовое задание для GREEN-API
## React + TypeScript + Vite

## Запуск проекта

Требуется Node.js `^22.12.0`, `^24.0.0` или `>=26.0.0` (рекомендуется 24.x) и npm.

Установите зависимости и запустите сервер разработки:

```sh
npm ci
npm run dev
```

Откройте адрес, который Vite покажет в терминале (обычно `http://localhost:5173/`).

Для проверки готовой сборки:

```sh
npm run build
npm run preview
```

## Тесты

После установки зависимостей запустите все тесты одной командой:

```sh
npm test
```
